# Be6A Lung-02（SigVie-003 / NCT06758401）最终预测报告

**主控制Agent 整合汇总 · 生成日期 2026-08-22**

> 目标试验：sigvotatug vedotin（SV，IB6-ADC）+ 帕博利珠单抗 **vs** 帕博利珠单抗单药；一线 PD-L1 TPS≥50% 晚期 NSCLC；开放标签、1:1、N≈714；**双主要终点 PFS(BICR)+OS。结果尚未读出。**
> 本报告整合临床数据解析Agent（检索执行日 2026-08-21）与预测因子生成Agent（2026-08-22）的输出，经主控Agent质检后汇总。所有数值均可追溯至下游 Agent 的分级信源。

## 1. 执行摘要

Be6A Lung-02 达到统计学显著性的概率估计为：**PFS 40%–55%，OS 20%–35%**，整体置信度**低（偏低）**。核心判断是：SV+帕博的Ⅰ期联合早期信号确属正向且随访已成熟未衰减（TPS≥1% cORR 50%、非鳞 53%、mDOR 8.1mo、DCR 90–95%），使 PFS 具备接近抛硬币的读出可能；但唯一已读出的同构核心圈先例 EVOKE-03（SG+帕博 vs 帕博单药、一线、TPS≥50%）已于 2026-06-08 失败（PFS 数值改善未达显著、OS「不太可能达标」），其失败机理——**帕博单药在 PD-L1 高人群已高度有效、对照门槛极高**——与目标试验直接相关且可转移，是压低两端概率的主导风险。因属**双主要终点（PFS 与 OS 须同时达标）**，且 OS 门槛更高、成熟度受限，故 **P(PFS)>P(OS)，而试验整体成功受 OS 这一较弱终点约束，实际「整体胜出」概率显著低于 PFS 单端数字。** 最大的单点不确定源是设计最同构的 TROPION-Lung08 顶线尚未公开（信息客观不存在），使核心圈完成态先例仅 n=1，据此如实下调置信度。

**分层因子体系（F1–F10）。** F1 早期疗效信号；F2 历史成功率（base rate，两层同心圈）；F3 样本量与统计功效；F4 靶点验证强度；F5 生物标志物富集策略；F6 对照组合理性；F7 监管沟通；F8 公司披露语言；F9 招募进度；F10 竞品格局。

**base rate 两层同心圈。** 核心圈=与目标试验设计几乎逐条对应者（ADC+PD-1 联合、一线、PD-L1 TPS≥50%、帕博单药对照）；扩展圈=放宽人群/机制/治疗线者。核心圈为主锚点，扩展圈仅作趋势背景。

**信源分级。** Tier1=公司/监管/CT.gov/同行评审期刊；Tier2=专业肿瘤媒体；Tier3=分析/预览/聚合（含立场倾向）。

**主控Agent质检要点（已执行）。** 逐条核对生成Agent数值与解析Agent证据的一致性（全部相符）；确认概率有可比先例支撑而非凭空外推；确认「单药二线失败→联合一线」转化逻辑被正确用作风险因素；确认 PFS/OS 差异已解释；确认区间未过窄、数据局限已声明。质检结论：**通过，无需返工**（`insufficient_data_flag=false`，且输出判定合格），保留四项caveat见下。

## 3. 正式预测

### 3.1 概率估计

| 终点 | 达到统计学显著性的概率区间 |
|---|---|
| **PFS（BICR）** | **40% – 55%** |
| **OS** | **20% – 35%** |
| **整体（双主要须双达标）** | 未给点估计；受 OS 约束，**实质低于 PFS 单端数字**（详见 3.4） |

置信度：**低（偏低）**。区间较宽而非精确点估计，系刻意反映证据稀薄与方向性张力。

### 3.2 关键支撑假设

1. **联合早期信号正向且随访成熟未衰减。** 2026 ASCO 摘要 8522（数据截止 2025-09-30、中位随访 10.6mo）：TPS≥1%(n=18) cORR 50%、非鳞(n=19) 53%、DCR 90–95%、mDOR 已由 NR 成熟为 8.1mo；富集人群 TPS≥50% cORR 80%（**n 仅=5**）。均显著高于 SV 单药 cORR 19%。相对早期切面（2025 ASCO n=21，随访 4.8mo）无负向衰减。（F1，Tier1）
2. **设计规范、PFS 把握度较足。** N=714、1:1、活性对照为一线 TPS≥50% 现行标准（帕博单药/KEYNOTE-024）、双主要 PFS(BICR)+OS，人群锁定 IO 获益最明确的 PD-L1≥50%。（F3/F5/F6，Tier1）
3. **安全性可管理、联合可执行。** 全人群治疗相关≥3级 TEAE 44%，71例中34例仍在治，未见明显阻断足剂量足疗程的信号。（F1 safety，Tier1）

### 3.3 关键风险因素

1. **唯一完成态同构核心圈先例失败，且失败机理可直接转移。** EVOKE-03/KEYNOTE-D46（SG+帕博 vs 帕博单药、一线、TPS≥50%，设计几乎逐条对应）2026-06-08 终止：PFS 数值改善未达显著、OS「不太可能达标」。公开归因为「帕博单药在 PD-L1 高人群已高度有效」——此为**对照臂强度**问题，与 ADC 靶点无关，故对目标试验同样成立。（F2 核心圈 0/1、F6，Tier1）
2. **对照门槛高 + 双主要须双达标。** 帕博单药一线 TPS≥50% 历史 mOS~26mo、ORR~45%；而联合在稳健切面(n=18) cORR 50% 对~45% 的增量有限，且 TPS<1% 与 TPS≥1% cORR **均为 50%、无 PD-L1 梯度**，削弱「PD-L1 富集→联合获益」的逻辑。（F1/F5/F6，Tier1–2）
3. **靶点级前瞻支撑弱 + 同药 OS 前科。** SigVie-002 总人群 OS 未达标，且探索性分析未见 IB6 表达的暴露-反应关系；本试验富集用的是**帕博的 PD-L1 而非 SV 自身靶点 IB6**，对「SV 组分是否真正贡献获益」缺乏靶点层面的前瞻依据。最强正向数字 TPS≥50% cORR 80% 仅 **n=5、CI 无法计算**。（F4/F5/F2 扩展圈，Tier1–2）

### 3.4 PFS 与 OS 差异解释（P(PFS)>P(OS)）

- **增益的读出位置不同。** ADC+IO 的增益最清晰地体现在缓解率与早期无进展（联合 cORR/DCR/mDOR 均优于单药），PFS 更易读出获益。
- **OS 门槛更高、成熟度受限。** 帕博单药 TPS≥50% 历史 OS 已达~26mo 量级，OS 受后线治疗稀释、需更长随访；且主要完成日被前移（Nov 2026→Aug 2026，**Tier3 来源**），进一步压低 OS 按期达显著的可能。
- **先例模式一致指向 OS 更难。** EVOKE-03 正是「PFS 改善但 OS 不太可能达标」模式；同药 SigVie-002 亦栽在 OS。
- **双主要终点的约束性。** 双主要意味 PFS 与 OS 须同时达标；即便 PFS 达标而 OS 不达标，整体仍算失败。故**整体成功概率受 OS 这一较弱终点约束，低于任一单端数字**——这是本预测最需被决策者注意的结构性结论。

## 4. SigVie-002 先例分析：单药失败的教训如何转化为对联合方案的判断

SigVie-002 / Be6A Lung-01（NCT06012435，703 例，SV 单药 vs 多西他赛，二线+非鳞 NSCLC，主要终点 OS）于 2026-06-22 topline：**总人群 OS 未达统计学显著**；预设亚组中仅 1 线既往治疗者（约 2/3）OS 与 PFS 呈更强趋势；探索性分析**未见 IB6 表达与获益的清晰暴露-反应关系**。

**主控Agent确认：下游已正确地将其用作「先例与教训」，而非预测靶子。** 转化逻辑如下：

1. **不做机械外推。** SigVie-002 与目标试验在**机制（单药 ADC 无 IO vs 联合 IO）与治疗线（二线+ vs 一线）**上均不同，故其失败**不被直接等同于**联合方案将失败；base rate 中仅归入扩展圈、低权重。这正确避免了「单药二线失败=联合一线必失败」的过度悲观误读。

2. **提炼可转移的教训（用作风险因素）。** 其真正可转移的信号是**靶点层面的**：IB6 虽在~90% NSCLC 表达、且为负向预后指标，但「表达量→临床获益」的人体验证在已读出Ⅲ期中**未成立**。因目标试验的富集用的是伙伴药的 PD-L1 而非 SV 自身的 IB6，这意味着对「SV 组分究竟贡献多少」**缺乏靶点级前瞻依据**——SV 的获益在联合方案里可能被强效的帕博背景所掩盖或替代，难以独立证实。

3. **与公司披露语言互证。** SigVie-002 失败后，Pfizer 措辞由「广谱催化剂/potential first-in-class」转向「联合 IO、更早治疗线为更有效的临床应用方向」，对二线单药明显降温（F8，Tier3 为主）。这与「把希望寄于一线联合」的方向一致，但属公司立场、非独立证据。

**结论：** SigVie-002 的教训被恰当地转化为「靶点级前瞻支撑弱」这一风险因素（风险 3），既未被忽略，也未被过度放大为对联合方案的直接判决。这一处理是本预测推理链中较为稳健的一环。

## 5. 框架可靠性声明（能力边界的诚实说明）

**本系统是结构化人类判断的辅助框架，不是客观预测机器。** 请如下理解本报告的性质与局限：

- **无法回测验证。** 目标试验尚未读出，本预测**无法用已知结果检验其准确性**。报告的价值在于**推理过程的可追溯性与证据的透明分层**，而非预测数字的绝对正确性。给出的是概率区间与显式假设，不是承诺。
- **base rate 样本极薄。** 核心圈完成态先例**仅 n=1（EVOKE-03，失败）**，远低于稳健推断所需的阈值。方向偏负的结论在很大程度上依赖 EVOKE-03 单例及其「对照臂过强」的读通——该读通虽因与靶点无关而可转移，但仍应以谦逊态度持有：**足够活跃的 ADC 仍可能越过门槛**（扩展圈 OptiTROP-Lung05 即显示 ADC+IO 能在更宽人群中达到 PFS 显著）。
- **最强正向数字最不稳健。** 支撑 PFS 的关键正向证据 TPS≥50% cORR 80% 仅 n=5、无法计算 CI，且 PD-L1 高低间 cORR 无梯度，与「PD-L1 富集→联合获益」逻辑存在张力。
- **单点不确定源未解。** 设计最同构的 TROPION-Lung08 顶线**信息客观不存在**（非检索遗漏），故未计入 base rate。若其日后读出：正向→上调并收窄区间；再度失败→强化下调。
- **部分前提依赖低级信源。** 「主要完成日前移→OS 成熟度受限」这一压低 OS 概率的前提，其完成日变更记录为 **Tier3 聚合**；F7 监管认定为「未发现」而非「确证不存在」，仍待官方列表最终确认。相关结论的证据基础相应偏弱。

**一句话：** 把本报告当作一份**证据分层清晰、假设可追溯的结构化判断**来使用，而非一个可信到可替代临床/商业尽调的「答案」。
